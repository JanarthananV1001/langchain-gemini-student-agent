# LangChain Gemini Student Agent

A LangChain Agent built with Gemini that answers student-related questions using multiple tools and a SQLite database.

## Features

- Get student name and department
- Get student marks
- Calculate total and average marks
- Check university passing rules
- Agent automatically selects the required tools

## Technologies

- Python
- Google Colab
- LangChain
- Gemini
- SQLite

## Files

- `LangChain_Gemini_Student_Agent.ipynb` — Complete assignment notebook
- `students.db` — SQLite student database
